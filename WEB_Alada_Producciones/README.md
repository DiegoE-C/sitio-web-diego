# Sitio Web Diego Espinoza

## Cosas que contiene el mini-proyecto
El minisitio web de desarollo tiene funciones como:
- Archivos HTML con la estructura básica de la página.
- Estilos CSS para el diseño.
- Archivos JavaScript para interactividad.
- Tambien Php
- Muchas imagenes en jpg o png
- Audios para la web 
- Json para ver su estructura
- Esta organizado sus carpeta como admin para js y php, assets para js, audio y css, backups para   tener un portafolio de imagenes para la estructura de la web, data para el json, doc que es para los documentos importantes de un work o pdf o de imagenes utiles para informacion, img para fotografias y logos o videos importantes, pages que es para el html y php que es la principal para poder ir a la url de la web.
## Lo que aprendi:
A organizar un sitio web en carpetas separando HTML, CSS, JS e imágenes pero dependiendo si su estructura es bien separada no es necesario hacerlo, ya que se puede entender bien.
Aprendi a subir y gestionar un proyecto en un repositorio Git Bash
A escribir documentaciones básicas para describir y explicar un proyecto web con README.md usando touch, git add README.md y tambien el git commit -m y el git push .
